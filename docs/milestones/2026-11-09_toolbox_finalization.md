# Toolbox finalization — 9 November 2026

The approved README and two complete workflow templates are implemented.
Expected reference hashes are optional binding checks; automatic observed
provenance and substantive compatibility checks remain. `nextseq_trim: null`
and `--no-nextseq-trim` truly omit NextSeq-specific treatment; numeric zero
continues to enable it. Scientific counting/normalization engines are unchanged.

The dev1 wheel passed compact installed acceptance on native macOS ARM64 and
Linux x86-64, including both full templates, exact counts, raw/RPM values and
restart/upstream preservation. See the [finalization report](../finalization_report.md)
for identities, regression results, limitations and retained private receipts.

Publication/staging inventories are proposals only. Legacy redistribution and
historical-record publication require owner decisions. The independent R-checker
warning remains deferred. No experimental analysis, commit, push or publication.
