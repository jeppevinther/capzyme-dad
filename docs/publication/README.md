# Public source inventory

CapZyme-DAD starts from a reviewed source export with a fresh Git history. The
internal development repository and its historical research/audit records are
not part of this public history. Original scientific scripts and author notices
are preserved; owner redistribution confirmation is recorded in
[legacy licensing](license_review.md).

- [Public source files](public_files.txt): exact public source-tree inventory.
- [Initial staging list](proposed_staging.txt): the same reviewed public files,
  rather than the internal repository's earlier incremental staging proposal.
- [Inventory](inventory.tsv): source-tree file disposition.
- [Excluded material](retained_review_files.txt): categories kept in the internal
  development archive; private filenames, locations and logs are not enumerated.

Build outputs, environments and synthetic/runtime data are generated outside Git.
The [initial-publication report](../publication_report.md) records the renamed
package identity and the checks run for this tree. Earlier acceptance reports
remain snapshot evidence for their explicitly named earlier artifacts.
